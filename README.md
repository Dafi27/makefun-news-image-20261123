## How it works

`main.py` (Python 3.13, standard library only) draws the 1024×1024 PNG
programmatically — a 5×7 pixel font, shape drawing, and its own PNG encoder
— and writes it to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `./out/entry.png`).
No network, no external files. Two runs produce byte-identical output.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
